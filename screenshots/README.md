# Screenshots

Pasta reservada para os prints exigidos pelo edital.

Como gerar:
1. `pip install -r ../requirements.txt` e configure o `.env`.
2. `python ../app/main.py` (ou `python app/main.py` da raiz).
3. Capture e salve aqui com estes nomes:
   - `01-login.png` — tela de login
   - `02-menu-secretario.png` — menu como Secretario (sem botões sensíveis)
   - `03-menu-coordenador.png` — menu como Coordenador (completo)
   - `04-alunos.png` — lista/cadastro de alunos
   - `05-matricula.png` — matrícula com lotação
   - `06-notas.png` — lançamento de notas/exame
   - `07-relatorios.png` — relatórios + fechar semestre + auditoria
